# Лабораторная работа №1 - Основы HTML и структура веб-страницы

## Тема работы

Создание HTML-страницы "О себе" с использованием базовой структуры HTML-документа, семантических тегов, изображения, списков (нумерованных и маркированных), ссылок и формы обратной связи.

## Вариант 2 - "Путешественник"

В соответствии с вариантом, страница посвящена теме путешествий. В разделе "Навыки" перечислены навыки, полезные во время восхождений на вершины, в разделе "Посещённые вершины" - список посещённых вершин в хронологическом порядке, а в боковой панели `<aside>` указано любимое место.

Для оформления использована бежево-оранжевая цветовая гамма.

## Структура страницы

На странице используются следующие элементы:

* `<header>` - шапка страницы с моим именем и заголовком (темой);
* `<ol>` - нумерованный список посещённых вершин (также используется для оглавления с навигационными ссылками);
* `<ul>` - маркированный список навыков;
* `<main>` - основной контент страницы;
* `<section>` - секции «Навыки» и «Проекты»;
* `<img>` - моя фотография с атрибутами `src`, `alt`, `width` и `height`;
* `<aside>` - дополнительная информация о любимом месте;
* форма обратной связи с полями имени, электронной почты и сообщения;
* `<footer>` - нижняя часть страницы с копирайтом и годом.

## Использованные технологии

* HTML5;
* [W3C Validator](https://validator.w3c.org) для проверки валидности HTML-кода;
* VSCode (с расширениями);
* [ChatGPT](https://chatpgt.com).
